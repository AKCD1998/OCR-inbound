# External Blockers

Last updated: 2026-07-22

These blockers disable only the affected live/production capability. Fake/Replay staging work must
continue.

| ID | Blocker | Disabled capability | Safe next action |
|---|---|---|---|
| EXT-001 | External first-five schema/DDL and milestone evidence unavailable | Claiming alignment/first-five completion or stage advance | Obtain read-only inventory/DDL and manually verified milestone evidence. |
| EXT-002 | Explicit ADA staging/test company, target authorization, process/control dump unavailable | Live Win32 draft trial | Owner/IT supplies staging target and authorizes non-destructive inspection. |
| EXT-003 | ATL grid order, lookup/unit popups, row commit/readback unproven | Live line entry/resume | Run sanitized, witnessed staging trials; never use production Save/Approve. |
| EXT-004 | Reliable ADA row-count/grand-total/doc-number readback unproven | Live reconciliation and save | Collect machine-readable staging observations; UNKNOWN remains fail. |
| EXT-005 | AdaAcc schema, approved SELECT query catalog, and least-privilege credential unavailable | Live cache refresh/duplicate lookup | IT provides read-only views/account and proves mutation denied. |
| EXT-006 | Save/Approve/Cancel semantics and ADA↔ERP number mapping unproven | Any real save/completion claim | Separate later authorized staging acceptance goal. |
| EXT-007 | Production reviewer authentication choice unresolved | Production review/save authorization | Owner/IT chooses Windows identity or app authentication. |
| EXT-008 | RPO, backup frequency, audit/artifact retention unresolved | Production operations | Owner/IT/legal sets values after staging restore evidence. |
| EXT-009 | 30-document live ADA staging acceptance not performed | Production activation and ≥95% live automation claim | Run a separately authorized live staging acceptance goal. |

Production automation, direct AdaAcc write, ADA Save/Approve, shared multi-workstation queue, and
identity/RPO/retention decisions are outside this goal's authority.
